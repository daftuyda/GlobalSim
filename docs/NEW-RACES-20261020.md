**Practice event ordering:** 4,681 races differ only in the ordering of simultaneous startup skills.
Every first ordering mismatch has Groundwork (skill 201601) at time zero in the simulated list.
The checked movement, results, skill identities, activation times, durations, and targets match in these races.

**Practice behaviour:** two new cases differ beyond event ordering:

These are separate symptoms: a very small position/finish difference and an earlier divergence that changes the result.
The first observed mismatch alone does not identify the failing mechanic.

They resemble the earlier initialization discrepancy family, without proving the same cause.
